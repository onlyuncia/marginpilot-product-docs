# Ограничения и зависимости MarginPilot

Расчёт зависит от данных 1С и Ozon. 1С — внутренняя система компании, но не часть MarginPilot.

## 1. Внешние зависимости

| ID | Зависимость | Влияние на процесс |
| --- | --- | --- |
| ВЗ-01 | Данные 1С | Если данные о товаре и затратах отсутствуют или устарели, расчёт экономики SKU становится менее надёжным. |
| ВЗ-02 | Ozon API | Через API система получает данные, отправляет цены и решения по акциям, проверяет применённые цены. Ответ на запрос ещё не означает, что цена изменилась на площадке. |
| ВЗ-03 | Комиссии, тарифы и условия акций Ozon | При изменении условий подготовленные цены могут потребовать нового расчёта. |
| ВЗ-04 | Продажи и рекламные расходы | Пока фактические данные не поступили, сравнить результат с прогнозом нельзя. |

## 2. Внутренние ограничения

| ID | Ограничение | Следствие для пользователя и результата |
| --- | --- | --- |
| ВО-01 | Цену подтверждает менеджер | MarginPilot рассчитывает и проверяет предложение, но не отправляет его без решения менеджера. |
| ВО-02 | Предупреждение не блокирует отправку | SKU ниже порога не отмечены по умолчанию, но менеджер может выбрать их и подтвердить отправку. Решение сохраняется в журнале. |
| ВО-03 | Прогноз относится к одной продаже SKU | Система оценивает экономику при заданной цене и расходах, но не прогнозирует спрос. |
| ВО-04 | План и факт появляются в разное время | При выборе цены используют плановые расходы. Фактические продажи и рекламные списания появляются позднее и могут отличаться от расчёта. |

Здесь подробно описана схема Ozon DBS; работа с другими схемами продаж в этот разбор не входит.
